# 2026-11-03 目标函数与网络结构

> 对应 HuggingFace《The Annotated Diffusion Model》，从 Defining an objective function 读到 The neural network 的 Network helpers 结束，Position embeddings 之前。
> 文中标「教材」的是原文结论，标「实测」的是在本机跑出来的数。

## 这两节要解决什么

前面已经确定：前向过程完全由 β 序列定死，反向过程被压缩成「学一个均值函数 μ_θ」。但还没说明白两件事：μ_θ 用什么目标函数学，以及它由什么网络承载。

第一节回答前者，把「最大似然」一步步化简成一个噪声的平方误差。第二节回答后者，选定 U-Net 并给出实现骨架。

## 一、从负对数似然到 ELBO

训练想让模型给真实样本 x_0 分配的概率尽量大，等价于让 `-log p_θ(x_0)` 尽量小。问题是这个量算不出来，它需要对所有中间路径积分：

```
p_θ(x_0) = ∫ p_θ(x_0, x_1, ..., x_T) dx_1 ... dx_T
```

T = 1000 重积分，没有解析解。

教材的办法是引入已知的前向过程 q，用恒等式绕过去：

```
log p(x_0) = ELBO + KL( q ‖ p_θ )
```

KL 恒非负，所以 `ELBO ≤ log p(x_0)`，它是个下界。优化 ELBO 等于把下界往上顶，下界顶到最高时与真实值相等。

「变分」这个词指的是：真实后验求不出来，于是从一族候选分布里挑一个最接近的 q。扩散的特殊之处是 q 不用学，前向过程本来就写死了。

**实测验证下界**（一维高斯共轭模型，`p(z)=N(0,1)`、`p(x|z)=N(z,0.25)`、`x=1.0`，解析可得 `log p(x) = -1.430510`）：

| q 的均值 | q 的标准差 | ELBO | log p − ELBO |
|---|---|---|---|
| 0.00 | 1.0000 | -4.2258 | 2.7953 |
| 0.40 | 0.7000 | -2.1075 | 0.6770 |
| 0.80 | 0.4472 | -1.4305 | **0.0000** |
| 1.20 | 0.4472 | -1.8305 | 0.4000 |

q 取真实后验时 ELBO 与 log p 差 2.22e-16，完全贴合。取先验时差 2.7953。

## 二、KL 散度与它的闭式解

KL 的定义是「用 q 编码 p 时多花的代价」：

```
KL(p ‖ q) = ∫ p(x) log( p(x)/q(x) ) dx
```

两个高斯之间有闭式解：

```
KL(N(μ₁,σ₁²) ‖ N(μ₂,σ₂²)) = log(σ₂/σ₁) + (σ₁² + (μ₁-μ₂)²)/(2σ₂²) - ½
```

推导只有三步。两个对数相减，合并常数项得 `log(σ₂/σ₁)`，剩下两个期望：

```
E_p[(x-μ₁)²] = σ₁²                          →  贡献 -½
E_p[(x-μ₂)²] = σ₁² + (μ₁-μ₂)²                →  贡献 (σ₁²+(μ₁-μ₂)²)/(2σ₂²)
```

第二条要拆 `(x-μ₂)² = ((x-μ₁)+(μ₁-μ₂))²`，交叉项期望为零。

**实测**（`p=N(0.5,4)`、`q=N(-1,2.25)`）：三项分别是 `-0.2877`、`+1.3889`、`-0.5000`，合计 `+0.6012`。直接数值积分 `∫ p log(p/q)` 得 `+0.601207`，差 3.33e-16。

KL 不满足对称性：`KL(N(0,4)‖N(0,1)) = 0.8069`，反方向 `0.3181`。所以它不是距离，只表示「用错编码多付的钱」。

## 三、L 拆成 T+1 项

因为整条链是马尔可夫的，ELBO 里的 KL 可以按时间步切开：

```
L = L_T  +  Σ_{t=2..T} L_{t-1}  +  L_0
```

三项的分工：

| 项 | 形式 | 说明 |
|---|---|---|
| L_0 | `-log p_θ(x_0∣x_1)` | 重建项，不是 KL 形式，所以原文说「除 L_0 之外」 |
| L_{t-1} | `KL( q(x_{t-1}∣x_t,x_0) ‖ p_θ(x_{t-1}∣x_t) )` | 主体，T−1 项 |
| L_T | `KL( q(x_T∣x_0) ‖ p(x_T) )` | 两个都是标准高斯，无参数，训练时当常数 |

## 四、每项是高斯 KL，化简成 L2

两边都是高斯，DDPM 把方差都设成 β̃，于是：

```
KL(N(μ̃, β̃) ‖ N(μ_θ, β̃)) = (μ̃ - μ_θ)² / (2β̃)
```

`log(σ₂/σ₁)` 和 `σ₁²/(2σ₂²)` 都因为方差相同而抵消，只剩均值的平方差。

再往下一步，均值由噪声决定：

```
μ_θ = (1/√α_t) · ( x_t − β_t/√(1-ᾱ_t) · ε_θ )
```

所以均值差等价于噪声差乘一个系数。实测（`β̃` 取各 t 的真实值，`Δε = 0.1`）：

| t | β̃_t | Δμ 对 Δε 的系数 | KL | ‖Δε‖²/2 | 权重 |
|---|---|---|---|---|---|
| 10 | 0.000238 | 0.0064 | 0.0009 | 0.0050 | 0.17 |
| 100 | 0.002035 | 0.0065 | 0.0001 | 0.0050 | 0.02 |
| 500 | 0.010031 | 0.0105 | 0.0001 | 0.0050 | 0.011 |
| 900 | 0.018008 | 0.0182 | 0.0001 | 0.0050 | 0.018 |

最后一列说明：KL 和 `‖ε − ε_θ‖²` 只差一个只跟 t 有关的正系数。DDPM 把它丢掉，直接优化 `‖ε − ε_θ‖²`，就是 L_simple。丢掉之后各时间步权重相同，小 t 那些项不再因为 β̃ 小而独占主导。

## 五、为什么可以只优化随机一项

`L` 是求和，求和可以写成「项数乘平均」：

```
L = T · E_{t~U}[ L_t ]
∇L = T · E[ ∇L_t ]
```

第二行成立是因为求导是线性的，先加后导等于先导后加。

所以随机抽一个 t 算 `∇L_t`，是真实梯度的无偏估计（差一个常数 T，吸收进学习率）。

**实测**（模拟一条中间高两头低的 L_t 曲线，真值平均 0.4320）：

| 采样次数 k | 估计值 | 与真值差 |
|---|---|---|
| 1 | 0.1655 | -0.2666 |
| 10 | 0.3889 | -0.0431 |
| 100 | 0.4634 | +0.0314 |
| 1000 | 0.4347 | +0.0027 |

单次标准差 0.3079，跟真实分布 0.3068 几乎一样。单次估计很粗糙，但无偏。

成本对比：全量每个 epoch 要 `1000 × 469 = 469,000` 次前向，随机采样只要 `469` 次。

**前提是闭式解。** 抽到 t=837 要能 O(1) 造出 x_837，否则只能循环加噪 837 次，随机采样反而更贵。所以「闭式解 → 能随机采 t → 一步训一次」是一条链。

## 六、三种参数化为什么选噪声

同一个量有三种写法，给两个就能定第三个：

```
x_0 = (x_t − √(1-ᾱ_t)·ε) / √ᾱ_t
μ   = (1/√α_t) · ( x_t − β_t/√(1-ᾱ_t)·ε )
ε   = (x_t − √ᾱ_t·x_0) / √(1-ᾱ_t)
```

代数上等价，数值上差很远。假设噪声估计差 0.01（ε 本身标准差为 1，即差 1%）：

| t | ᾱ_t | 折算成 x_0 的差 | 放大倍数 |
|---|---|---|---|
| 10 | 0.9981 | 0.0004 | 0.0 |
| 100 | 0.8970 | 0.0034 | 0.3 |
| 500 | 0.0786 | 0.0342 | 3.4 |
| 900 | 0.0003 | 0.6027 | 60.3 |
| 1000 | 0.00004 | **1.5741** | **157.4** |

预测 x_0 的问题是 `1/√ᾱ_t` 在大 t 时把误差炸开。预测 μ 的问题是 `μ ≈ x_t × 1.01`，等于让网络学恒等映射，梯度信号弱。预测 ε 的目标恒为 `N(0,I)`，尺度与 t 无关。

实测反解来回一圈无损失：`(x_t, ε)` 反算 x_0 差 4.4e-16，`(x_0, x_t)` 反算 ε 差 1.1e-16。

## 七、后验均值 A·x₀ + B·x_t 的完整推导

这是这一节里唯一需要动笔的推导，分四步。

### 第一步：贝叶斯

记 `z = x_{t-1}`。把 `P(z, x_t | x_0)` 按两种顺序拆开，左边那项用一次马尔可夫假设 `P(x_t|z,x_0) = P(x_t|z)`：

```
                P(x_t|z) · P(z|x_0)
P(z|x_t,x_0) = ─────────────────────
                    P(x_t|x_0)
```

分母不含 z，只是归一化常数。**这也是必须带 x_0 的原因**：分子第二项需要它。

### 第二步：两个因子都写成关于 z 的高斯

似然要翻过来。用反解看最直观：`x_t = √α_t z + 噪声`，所以 `z = (x_t − 噪声)/√α_t`，均值 `x_t/√α_t`，方差 `β_t/α_t`。

代数上叫配方，实测验证（`z=1.05`）：

```
‖x_t − √α z‖²/(2β)        = 0.00344374
α(z − x_t/√α)²/(2β)       = 0.00344374      差 1.31e-16
```

先验不用动，本来就是关于 z 的：`N(√ᾱ_{t-1}x_0, 1-ᾱ_{t-1})`。

### 第三步：精度加权

两个高斯相乘，精度相加得方差，分子按精度加权得均值。

`t=500` 的实测：似然精度 `98.6012`，先验精度 `1.0862`，**相差 90 倍**。

| 因子 | 均值 | 方差 | 精度 | 权重 |
|---|---|---|---|---|
| 似然 | 1.041642 | 0.010142 | 98.60 | 98.91% |
| 先验 | 0.366278 | 0.920616 | 1.09 | 1.09% |
| 后验 | 1.034283 | 0.010031 | 99.69 | — |

后验落在 1.0343，几乎贴着似然的中心。先验想把结果拉到 0.3663，但只有 1.09% 话语权，最终只把均值拽下来 `0.0073`。

两个地方的量纲要分清：精度相加后得到的是精度，要再取一次倒数才是方差。直接对方差相加是错的，两个独立观测合并后方差应该变小，不是变大。

### 第四步：通分得到闭式

**通分。** 分母是 `β_t(1-ᾱ_{t-1})`，分子是两项之和：

```
分子 = α_t(1-ᾱ_{t-1}) + β_t
     = α_t - α_t·ᾱ_{t-1} + β_t
     = α_t - ᾱ_t + (1-α_t)          ← α_t·ᾱ_{t-1} = ᾱ_t，β_t = 1-α_t
     = 1 - ᾱ_t
```

实测：`0.989960 × 0.920616 + 0.010040 = 0.921413`，正好等于 `1 - 0.078587`。

于是：

```
v = β_t(1-ᾱ_{t-1}) / (1-ᾱ_t) = 0.00924298 / 0.921413 = 0.010031
```

**拆项。** 均值 `m = v × (m₁p₁ + m₂p₂)`，先不乘，分别算两个乘积：

```
m₁p₁ = (x_t/√α_t)(α_t/β_t) = x_t·√α_t/β_t     = 102.707584
m₂p₂ = (√ᾱ_{t-1}x_0)/(1-ᾱ_{t-1})              =   0.397861
```

差别 258 倍。再分别乘 v：

```
B = v·√α_t/β_t              = 0.99410671
A = v·√ᾱ_{t-1}/(1-ᾱ_{t-1})  = 0.00307005
```

**约分。** 把 v 代进去，能约掉一些东西：

```
B = [β_t(1-ᾱ_{t-1})/(1-ᾱ_t)] · √α_t/β_t           = √α_t(1-ᾱ_{t-1})/(1-ᾱ_t)     β_t 约掉
A = [β_t(1-ᾱ_{t-1})/(1-ᾱ_t)] · √ᾱ_{t-1}/(1-ᾱ_{t-1}) = β_t√ᾱ_{t-1}/(1-ᾱ_t)      (1-ᾱ_{t-1}) 约掉
```

两个约掉的东西不同，所以最后长得不对称。

### 验证

网格搜峰和曲率，不依赖任何公式：

| | 网格算出 | 公式给出 |
|---|---|---|
| 均值 | 1.03428325 | 1.03428325 |
| 方差 | 0.01003137 | 0.01003136 |

A、B 有一个恒等式：`A·√ᾱ_t + B = √α_t`，实测六组吻合到 1e-14。含义是「如果 x_t 没有噪声，μ̃ 应退化成 √α_t·x_0」，即确定性的退一步。

## 八、U-Net 与 bottleneck

教材说扩散的反向网络结构类似自编码器：编码器把图像压进一个更窄的「瓶颈」，解码器再还原。瓶颈窄，网络只能保留最重要的信息。

**自编码器的瓶颈是维度瓶颈。** 实测线性瓶颈（等价 PCA）在 Fashion-MNIST 3000 张图上：

| 保留维度 | 累积方差占比 | 重建 MSE |
|---|---|---|
| 1 | 29.13% | 0.061751 |
| 8 | 69.85% | 0.026275 |
| 32 | 83.29% | 0.014565 |
| 128 | 93.51% | 0.005659 |
| 784 | 100.00% | 0.000000 |

降到 32 维还保住 83% 方差，轮廓能认；降到 2 维只剩 47%，基本是灰块。

**U-Net 的瓶颈不是这个意思。** 它压的是空间分辨率，不是总元素数。按 `dim=64`、通道 64→128→256 的配置：

| 层 | 形状 | 元素数 |
|---|---|---|
| 输入 | 28×28×1 | 784 |
| 第一层 | 28×28×64 | 50,176 |
| 下采样一次 | 14×14×128 | 25,088 |
| 下采样两次 | 7×7×256 | 12,544 |

最底层 12,544，比输入图像还大 16 倍。压掉的是 28×28 那个网格，相邻像素被揉进通道。所以 U-Net 的瓶颈作用是「强迫网络在低分辨率上做全局决策」，细节则靠 skip connection 送过去。

## 九、残差连接

`Residual` 模块把任意函数包成 `f(x) + x`。原文说它「greatly improving gradient flow」，借的是 ResNet 的说法。

**梯度的机制**：`dy/dx = f'(x) + 1`，那个 1 跟 f 学成什么样无关。20 层的对比（每层局部导数 0.5）：

| 层数 | 纯串联 0.5ⁿ | 残差 1.5ⁿ |
|---|---|---|
| 10 | 9.77e-04 | 5.77e+01 |
| 20 | 9.54e-07 | 3.33e+03 |
| 50 | 8.88e-16 | 6.38e+08 |

乘法会让梯度归零，加法不会。代价是 f' 大时可能爆，要靠初始化压住。

**行为上的意义**：残差把「学一个完整变换」变成「学一个修正量」。要让输出等于 `1.1x`，纯串联要把权重学到 1.1，残差只要学到 0.1。默认状态从「输出 0」变成「原样通过」。

一个常见误解是「加了 x 输出会变大」。不会，f 可以学成负数，`f(x)+x` 的表达能力和 `f(x)` 完全一样，只是换了原点。

**一个措辞上的区分**：ResNet 的残差是同层 `f(x)+x`，U-Net 的 skip 是跨层把编码器特征送到解码器。数学形式都是加法，但 U-Net 的 skip 主要是为了保边界细节，梯度只是附带好处。

## 十、网络辅助函数

六个函数里五个是糖，只有 `Downsample` 是设计选择。

```
exists(x)        判断非 None，不用 if x（会把 0 和空张量判假）
default(val, d)  没传就用默认值，d 可以是函数（延迟求值）
num_to_groups    按 divisor 切分，余数单独一组，当前网络没用到
Residual(fn)     f(x) + x，要求输入输出形状一致
Upsample         最近邻 ×2 + 3×3 conv
Downsample       Rearrange + 1×1 conv
```

`Downsample` 那一行注释写的是 `No More Strided Convolutions or Pooling`。它把 `2×2` 空间块搬到通道维：

```
Rearrange("b c (h p1) (w p2) -> b (c p1 p2) h w", p1=2, p2=2)
```

输入 `(2,64,28,28)` 重排后是 `(2,256,14,14)`，元素数前后都是 100,352，一个不少。

跟 stride 卷积对比：

| 写法 | 输出 | 参数量 |
|---|---|---|
| `Conv2d(64, 256, 3, stride=2, padding=1)` | (2,256,14,14) | 147,712 |
| `Rearrange + Conv2d(256, 256, 1)` | (2,256,14,14) | **65,792** |

差距来自卷积核大小（9 对 1）。但更重要的是信息有没有丢：`stride=2` 在滑动时跳过一半像素，Rearrange 把每个像素都保留，只换摆放方式。对一个要逐位置预测噪声的网络，每个位置都有意义。

`dim * 4` 里的 4 就是 `p1 × p2`，改成 `p1=4,p2=4` 就要写 `dim*16`。

## 概念清单

### 目标函数与下界

| 概念 | 含义 |
|---|---|
| 负对数似然 | `-log p_θ(x_0)`，训练想最小化的量。它算不出来，因为要对所有中间路径积分 |
| ELBO | `log p(x_0) - KL(q‖p_θ)`，可算的下界。q 取真实后验时与 log p 相等（实测差 2.22e-16） |
| 变分推断 | 真实后验求不出，从一族候选里挑最接近的替代。扩散里 q 不用学，前向过程已定死 |
| KL 散度 | `Σ p log(p/q)`，衡量用 q 编码 p 多花的代价。恒 ≥ 0，不对称，不是距离 |
| 高斯 KL 闭式解 | `log(σ₂/σ₁) + (σ₁²+(μ₁-μ₂)²)/(2σ₂²) - ½`，三项分别来自常数、两个期望 |
| 条件高斯 | 给定条件下仍是高斯。前向每步、反向每步都是这个形式 |

### 损失分解

| 概念 | 含义 |
|---|---|
| L_0 | 重建项 `-log p_θ(x_0∣x_1)`，唯一不是 KL 形式的一项 |
| L_{t-1} | `KL(q(x_{t-1}∣x_t,x_0) ‖ p_θ(x_{t-1}∣x_t))`，主体，共 T−1 项 |
| L_T | `KL(q(x_T∣x_0) ‖ p(x_T))`，两个标准高斯之间，无参数，训练时忽略 |
| 同方差 KL | 两边方差都设成 β̃ 时，`KL = (μ̃−μ_θ)²/(2β̃)`，只剩均值的平方差 |
| L_simple | `‖ε − ε_θ‖²`，丢掉随 t 变化的权重。丢掉后各时间步等权，小 t 不再独占主导 |
| 无偏估计 | 随机抽一个 t 算梯度，期望等于真实梯度的 1/T。单次标准差 0.3079，与分布本身 0.3068 相当 |

### 后验推导

| 概念 | 含义 |
|---|---|
| 后验均值 | `μ̃ = A·x_0 + B·x_t`，`A = β_t√ᾱ_{t-1}/(1-ᾱ_t)`，`B = √α_t(1-ᾱ_{t-1})/(1-ᾱ_t)` |
| 后验方差 | `β̃ = β_t(1-ᾱ_{t-1})/(1-ᾱ_t)`，t=500 时 0.010031，代码里 `posterior_variance` 就是它 |
| 精度 | 方差的倒数 `1/σ²`，表示「有多确定」。独立信息源的精度可直接相加 |
| 精度相加 | `1/v = 1/v₁ + 1/v₂`，得到的是精度，要再取倒数才是方差。方差直接相加会让结果更不确定，是错的 |
| 均值归一化 | `μ = v(μ₁/v₁+μ₂/v₂)`。括号里是 `μ/v`，乘 v 才回到均值尺度，此时两个权重之和为 1 |
| 恒等式 | `A·√ᾱ_t + B = √α_t`。保证「无噪声时 μ̃ 退化成 √α_t·x_0」 |
| 误差放大 | 预测 x_0 时误差被 `1/√ᾱ_t` 放大，t=1000 时 ε 差 0.01 变成 x_0 差 1.57，放大 157 倍 |
| 三种参数化 | x_0、μ、ε 三者互相可换算，给两个定第三个。选 ε 是因为目标恒为 `N(0,I)`，尺度与 t 无关 |

### 网络结构

| 概念 | 含义 |
|---|---|
| bottleneck | 编码器和解码器之间的窄层。自编码器压维度，U-Net 压空间分辨率（28→7），元素数反而升到 12,544 |
| U-Net | 先下采样再上采样，对称结构。DDPM 用它承载 ε_θ，输入输出同形状 |
| skip connection | 把编码器某层特征直接送到解码器同分辨率层，保细节。区别于同层残差 |
| 残差连接 | `f(x) + x`，梯度 `f'(x)+1` 保证不衰减。默认状态从「输出 0」变成「原样通过」 |
| Rearrange | einops 的操作，把 `2×2` 空间块搬到通道。`(2,64,28,28)` → `(2,256,14,14)`，元素数不变 |
| 1×1 卷积 | 只做通道混合，不看空间。参数量 65,792 对 3×3 stride 卷积的 147,712 |
| 最近邻上采样 | `mode="nearest"` 只复制像素，不插值。补细节的决定留给后面的卷积 |
