# 2026-11-06 时间步编码与残差块

> 对应 HuggingFace《The Annotated Diffusion Model》，从 Position embeddings 读到 ResNet block 结束，Attention module 之前。
> 标「教材」的是原文结论，标「实测」的是在本机跑出来的数。

## 这一节要解决什么

上一节确定了损失函数和三种参数化，模型要学的是 ε_θ(x_t, t)。但 t 怎么进网络、网络长什么样，还没说。

这一节回答两件事：t 是个标量，怎么变成网络能吃的向量；U-Net 的基本积木块由什么组成。

## 一、为什么必须把 t 喂进去

原文的说法是「参数在时间上共享，所以需要位置编码让网络知道自己在哪个噪声级别」。

拆开看。U-Net 只有一套权重，1000 个时间步共用。给定同一个 x_t，要预测的 ε 取决于 t：t 小的时候 x_t 几乎是原图，噪声只占一点点；t 大的时候 x_t 基本就是噪声本身。同一数值范围，两种完全不同的任务。

不给 t，网络只能学一个折中解。

这里有个对照能说明问题：图像的空间位置为什么不需要编码？因为卷积核在图上滑动，位置感是结构自带的。而 t 是外挂进来的标量，网络里没有任何地方能感受到它，必须显式编码。

## 二、不直接喂标量的三个原因

尺度不匹配。t 在 [0, 999]，像素在 [-1, 1]，差三个数量级。

信息量太少。一个标量只能说「数字是 500」，说不了「500 对应多强的噪声」。

没有距离概念。500 和 501 差 1，0 和 999 差 999，但对网络来说这只是两个数，它不知道哪个更近。

## 三、正弦编码怎么构造

原式来自 Transformer：

```
PE(t, 2i)   = sin(t / 10000^(2i/d))
PE(t, 2i+1) = cos(t / 10000^(2i/d))
```

`t` 是时间步，`i` 是频率编号（0 到 15），`d` 是总维度 32。

把指数整理一下：

```
1 / 10000^(2i/d) = 10000^(-2i/d) = e^(-2i·ln10000/d)
```

代码里写成 `exp(-i · ln(10000)/(half_dim-1))`，也就是 `10000^(-i/15)`。

为什么是 15 而不是 16：16 个频率之间有 15 个间隔。首项 1，末项 1e-4 = 10000^(-1)，等比数列的公比就是 10000^(-1/15)。除 16 的话末项只能到 1.78e-4，够不到 1e-4。

实测 16 个频率：

```
1.000000  0.541170  0.292864  0.158489  0.085770  0.046416  0.025119  0.013594
0.007356  0.003981  0.002154  0.001166  0.000631  0.000341  0.000185  0.000100
```

公比恒为 1.847850。

## 四、为什么要多个频率

单个频率不够用。

只有高频（周期 6.3 步）：t=0 和 t=6.3 读数一样，远距离分不开。
只有低频（周期 62832 步）：t 从 0 到 999 只转了 1.6% 圈，相邻步的数值差小于 0.01，分辨不出来。

两者一起才行。跟二进制一个道理：低位变化快管精度，高位变化慢管范围。

实测 1000 个 t 的编码：最近的一对距离 1.1514，t=0 与 t=999 相距 4.7136。

## 五、sin 和 cos 为什么配对

只用 sin 会出别名。因为 `sin(θ) = sin(π - θ)`，两个角度给同一个读数。

t=1 时 sin(1)=0.8415；另一个角度 2.1416 的 sin 也是 0.8415。只看 sin 分不开。加上 cos：cos(1)=0.5403，cos(2.1416)=-0.5403，符号相反，立刻区分。

几何上，(cos θ, sin θ) 是单位圆上一点的坐标，θ 在 [0, 2π) 内唯一决定这个点。

实测对比：同样 16 个频率只取 sin，1000 个 t 里最近一对是 t=821 和 t=822，距离 0.0975；配对后最近一对 1.1514，差 12 倍。

代价是维度翻倍。dim=32 时只有 16 个频率可用。

## 六、形状上的两个坑

**原文说输入是 `(batch_size, 1)`，输出 `(batch_size, dim)`，这两句不能同时成立。**

实测：

| 输入 | 输出 |
|---|---|
| `(4,)` | `(4, 32)` |
| `(4, 1)` | `(4, 1, 32)` |

这个类本身对输入形状没有要求，只在最后一维后面追加 32 维，从不报错。但接进 U-Net 后会崩，因为下游的 `rearrange(time_emb, "b c -> b c 1 1")` 只认 2 个轴。

原博客自己的训练和采样代码传的都是 1 维：`torch.randint(0, timesteps, (batch_size,))` 和 `torch.full((b,), i, ...)`。

**dim 必须是偶数。** dim=33 时 `half_dim=16`，输出只有 32 维，第 33 维静默消失，后面的 Linear 会报维度不符。

## 七、编码怎么进网络

不是做加法，是调制。

```
time_mlp: Sinusoidal(32) → Linear(32,128) → GELU → Linear(128,128)
```

然后在每个 ResnetBlock 里：

```python
time_emb = self.mlp(time_emb)                     # (B,128) → (B, dim_out*2)
time_emb = rearrange(time_emb, "b c -> b c 1 1")  # 变四维，可广播
scale, shift = time_emb.chunk(2, dim=1)           # 劈成两半
x = x * (scale + 1) + shift                       # 调制归一化后的特征
```

`scale + 1` 是为了让初始状态接近恒等变换。如果没这个 1，scale 初始接近 0，整个特征被清零。

这套机制在 StyleGAN 里叫 AdaIN，在扩散模型里一般叫 AdaGN。

## 八、Wide ResNet

原文说 DDPM 用的是 Wide ResNet block。Wide 的意思是加宽而不是加深。

WRN 的命名是 WRN-n-k：n 是卷积层总数，k 是宽度因子。

```
N = (n - 4) / 6     每组 block 数
```

WRN-40-4 就是每组 6 个 block，共 18 个 block。通道数是基础值 16 乘 k，三个 group 为 16k / 32k / 64k，k=4 时是 64 / 128 / 256。

参数量约正比于 k²。

论文的核心结论在 CIFAR-10 上：WRN-40-4 用 8.9M 参数达到 4.52% 错误率，1001 层 PreAct ResNet 用 10.2M 参数是 4.62%。层数是对方的二十五分之一。

原因：深度的收益边际递减，宽度可以并行，宽度还能给梯度多条路径。

## 九、Weight Standardization

原文说 Phil Wang 把标准卷积换成了「权重标准化」版本。注意正文引的是 Kolesnikov et al. 2019，这是笔误。WS 的正确出处是 Qiao et al., arXiv:1903.10520，代码注释里写的正是这个。

BN 标准化的是激活值，WS 标准化的是权重本身：

```
ŵ = (w - μ_w) / sqrt(σ_w² + ε)
```

关键是 μ 和 σ 在哪些维度上算。代码里：

```python
mean = reduce(weight, "o ... -> o 1 1 1", "mean")
```

`weight` 形状 `(o, i, kh, kw)`，这个表达式把 i、kh、kw 压掉，只留 o。所以每个 filter 单独做一次 z-score。

dim=64 的 3×3 卷积，每个 filter 有 576 个权重，各自减均值除标准差。

实测：128 个 filter 标准化前 std 在 0.0229 到 0.0252 之间，标准化后变成 0.9906 到 0.9922。

**不是精确的 1.0**，因为 eps=1e-5 相对方差（约 0.00053）占了 1.9%，开方后把 std 压低约 1%。

论文的解释是平滑 loss landscape，降低 loss 和梯度的 Lipschitz 常数。换成能感知的说法：权重被约束在单位球附近，输出对输入的小扰动不会剧烈反应，可以用更大的学习率。

WS 没有可学习参数，是纯变换。这一点和 Weight Normalization（Salimani 2016，把权重拆成方向和长度，长度可学习）不同。

## 十、GroupNorm

BN 的死穴是统计量依赖 batch。batch=8 时每个通道只有 8192 个数估统计量，噪声大；batch=1 直接失效。

GN 不看 batch，把 C 个通道分成 G 组，每组内部算统计量。`dim=64, groups=8` 时每组 8 个通道。

四种归一化的区别只看统计量覆盖哪一块：

| 方法 | 覆盖 | 依赖 batch |
|---|---|---|
| BN | (N, H, W) 每通道 | 是 |
| LN | (C, H, W) 每样本 | 否 |
| IN | (H, W) 每样本每通道 | 否 |
| GN | (C/G, H, W) 每样本每组 | 否 |

DDPM 原论文在 TPU 上用 batch 128，可以随便用 BN。复现没有 TPU，Phil Wang 换成 GN，本质是让代码在任何卡上都能跑。官方实现用 32 组，这个版本用 8 组。

## 十一、WS 和 GN 为什么配

BN 干了两件事：归一化激活值，以及隐式约束权重尺度。后一件事是因为 BN 之后权重整体放大 2 倍，输出也会被归一化拉回来。

GN 只接手了第一件，没有第二件。

WS 补的正是第二件。Qiao 那篇的结论：WS 配 GN，在每张卡只有 1 张图的极端情况下能追平甚至超过大 batch 的 BN，代价是多两行代码。

原文那句 "works better in combination with group normalization" 说的就是这个。

## 十二、BN 的「状态」问题

这一条是读代码时容易忽略的，但影响很大。

BN 有两套统计量：训练时用当前 batch 现算的，推理时用训练过程中累积的滑动平均 `running_mean` / `running_var`。

`running` 的更新是 `running = 0.9 × running + 0.1 × batch_stat`，慢慢逼近真实分布。

实测同一个输入：

```
train mode : out mean -0.0000  std 1.0010
eval  mode : out mean +3.8748  std 1.7164
max abs diff: 5.9348
```

差这么多是因为 `running_mean` 只更新了 1 步，还是从 0 开始的值。训 200 步后 `running_mean` 收敛到 5 附近，eval 输出均值变成 -0.068。

两个后果：

训练早期用 eval 模式跑验证集，指标会很难看，不是模型差，是 running 没收敛。

忘了切 eval，推理时一直用当前 batch 统计量。batch 只有一张图时，BN 把这张图自己标准化，等于把信息抹掉，而且同一张图放进不同 batch 会得到不同结果。

GN 没有 running 统计量，训练推理行为一致，这也是它在小 batch 场景更省心的原因。

## 十三、残差块的结构

普通块学完整映射 `h = F(x)`。残差块学差异 `h = F(x) + x`。

这个改动有两层作用。

**目标难度变了。** 如果某个块的最优解是「什么都不做」，普通块要让卷积核学成单位矩阵，残差块只要让 F(x)=0，把权重压到 0 就行。初始化就在 0 附近，L2 正则也往 0 拉。

**梯度多了一条通路。** `dh/dx = F'(x) + 1`。普通块乘 F'(x)，残差块乘 (F'(x)+1)，那个 1 保证梯度至少有一条系数为 1 的回路。

实测 50 个块，第一层卷积拿到的梯度范数：

| 块数 | 普通块 | 残差块 |
|---|---|---|
| 5 | 4.871e-06 | 5.835e-02 |
| 10 | 8.527e-11 | 5.777e-02 |
| 20 | 5.986e-20 | 6.508e-02 |
| 40 | 0.000e+00 | 6.658e-02 |

普通块每加 5 层掉四到五个数量级，40 层直接归零。残差块几乎不变。

**上面是无 BN 的情况。有 BN 时梯度不会消失，反而会爆**（50 块普通网络第一层梯度 6.081e+04）。所以「梯度传不回去」这个解释只对无归一化的深网络成立。带 BN 的退化主要是优化景观问题，不是梯度消失。两个机制并存，残差对两个都有用。

## 十四、卷积的通道机制

理解 U-Net 代码绕不开这个，原文没细讲。

**一个 filter 是立体的，深度等于输入通道数，个数等于输出通道数。**

`Conv2d(64, 64, 3)` 的权重是 `(64, 64, 3, 3)`：64 个 filter，每个 filter 64 层（对应 64 个输入通道），每层 3×3。

一个 filter 在一次滑动中做的事：64 层各算一个乘积和，再把 64 个结果相加，得到 1 个数。

```
out[b, o, h, w] = Σ_i Σ_kh Σ_kw W[o,i,kh,kw] · x[b,i,h+kh-1,w+kw-1] + bias[o]
```

所以一个输出元素要算 `64 × 9 = 576` 次乘加。整个卷积约 3 亿次。

核滑遍 `H × W` 个位置，128 个 filter 各滑一遍，就得到 128 张图。

`Conv2d(64, 64, 3)` 输入输出都是 64 不是通道守恒，是两处碰巧都填了 64。

**1×1 卷积**就是核尺寸为 1 的普通卷积。每个 filter 只在该位置看 64 个通道，做加权求和。数学上等于一个 `(128, 64)` 的矩阵在每个像素位置上复用。

用它对齐通道是因为它只做通道混合，不动空间结构，符合同样语义的前提下参数最少（64→128 是 8,320，而 3×3 是 73,856，差 8.88 倍）。

## 十五、三个类的代码

**WeightStandardizedConv2d**：继承 `nn.Conv2d` 只重写 forward，参数注册沿用父类。`eps` 按精度选，float32 用 1e-5，半精度用 1e-3。最后直接调 `F.conv2d` 传标准化后的权重，`bias` 不参与标准化。

**Block**：`Conv → GroupNorm → (scale/shift 调制) → SiLU`。

调制放在 norm 之后、act 之前。因为要调制的是已经标准化好的特征，放在 norm 之前会被抹掉。

**ResnetBlock**：两个 Block 加一条旁路。

```python
self.block1 = Block(dim, dim_out)
self.block2 = Block(dim_out, dim_out)
self.res_conv = nn.Conv2d(dim, dim_out, 1) if dim != dim_out else nn.Identity()
```

只有 block1 带时间调制，block2 不带。一个 ResnetBlock 内两次卷积共享同一个时间步信息，注入一次就够。

`nn.Identity()` 是「什么都不做」的层，用它而不是 None 是为了让 `self.res_conv(x)` 两种情况都能写。

最后 `return h + self.res_conv(x)` 没有 SiLU，和经典 ResNet 的 `ReLU(F(x)+x)` 不同。因为 Block 内部最后已经激活过，下一次进 Block 时第一个操作是卷积，相当于激活推迟了一层。

实测 `ResnetBlock(64, 128, time_emb_dim=256)` 的形状：

| 步骤 | 形状 | 参数 |
|---|---|---|
| 输入 | `(2, 64, 8, 8)` | — |
| block1 | `(2, 128, 8, 8)` | 74,112 |
| block2 | `(2, 128, 8, 8)` | 147,840 |
| res_conv | `(2, 128, 8, 8)` | 8,320 |
| mlp | — | 65,792 |

合计 296,064。

## 十六、两个 mlp 别混

`Unet.time_mlp` 全局只做一次，把标量 t 变成 `(B, 128)` 的通用表示，所有 block 共享。

`ResnetBlock.mlp` 每个 block 各有一个，把 `(B, 128)` 翻译成自己需要的 `(B, dim_out*2)`。因为不同层级的 dim_out 不同（64、128、256、512），每个 block 得有自己的 mlp 做维度对齐，同时学自己的调制强度。

`mlp` 这个名字不严谨，这里只有一个 Linear，没有「多层」。

## 概念清单

### 时间步编码

| 概念 | 含义 |
|---|---|
| position embedding | 把 t 这个离散标量映射成向量的操作。名字借自 Transformer，那里的「位置」是词在句子里的序号，这里是扩散时间轴上的坐标 |
| sinusoidal encoding | 用一族不同频率的正弦函数在 t 处的读数组成向量。第 i 个频率 `freq_i = 10000^(-i/(d/2-1))`，第 i 维取值 `sin(t·freq_i)` 与 `cos(t·freq_i)` |
| 频率公比 | 相邻两档频率的比值 `10000^(1/15) = 1.847850`。16 个频率跨 4 个数量级，覆盖从周期 6.3 步到 62832 步 |
| sin/cos 配对 | 同一频率占两个维度，`(cos θ, sin θ)` 是单位圆上的坐标，θ 在 [0,2π) 内唯一。只用 sin 会有别名，因为 `sin θ = sin(π-θ)` |
| 别名 | 不同的 t 算出相同的编码。实测只取 sin 时，1000 个 t 里最近一对距离 0.0975；配对后是 1.1514 |
| scale/shift 调制 | `x * (scale + 1) + shift`。scale 和 shift 由 t 的编码经 Linear 得到，通道数各等于 dim_out。`+1` 让初始状态接近恒等变换 |
| AdaGN | 用 scale/shift 调制 GroupNorm 输出的做法。StyleGAN 里同类机制叫 AdaIN |

### 网络结构

| 概念 | 含义 |
|---|---|
| Wide ResNet | 加宽而不是加深的 ResNet。命名 WRN-n-k，n 是卷积层数，k 是宽度因子，每组 block 数 `N = (n-4)/6` |
| 宽度因子 k | 每层通道数 = 基础通道 16 × k。k=4 时三个 group 是 64/128/256，参数量约正比于 k² |
| 残差连接 | `h = F(x) + x`。梯度 `dh/dx = F'(x) + 1`，那个 1 保证深层也有系数为 1 的回路 |
| 恒等分支 | 把输入原样送到加法处的那条路。通道数不同时用 1×1 卷积调整，相同时用 `nn.Identity()` |
| ResnetBlock | 两个 Block 加一条旁路。只有 block1 注入时间调制，block2 不注入 |

### 归一化

| 概念 | 含义 |
|---|---|
| BN | 对 `(N, H, W)` 求统计量，每个通道一组。`y = γ·(x-μ)/sqrt(σ²+ε) + β`，γ 和 β 可学习 |
| running_mean | BN 在训练中累积的滑动平均，`running = 0.9·running + 0.1·batch_stat`。推理时用它，训练时用当前 batch 的 |
| model.eval() | 切换 BN 用 running 统计量、关闭 dropout。不切会导致同一输入在不同 batch 下输出不同 |
| GroupNorm | 对 `(C/G, H, W)` 求统计量，每个样本每组一组。不看 batch，没有 running 统计量 |
| Weight Standardization | `ŵ = (w-μ_w)/sqrt(σ_w²+ε)`，在每个 filter 内部（`i×kh×kw` 维度）做 z-score。零参数 |
| ε 的影响 | float32 用 1e-5。实测标准化后 filter 的 std 是 0.9906 不是 1.0，因为 eps 占方差的 1.9% |
| Lipschitz 常数 | 函数输出变化量与输入变化量之比的上界。WS 降低它，等于让 loss 曲面更平，可以用更大学习率 |

### 卷积与通道

| 概念 | 含义 |
|---|---|
| filter | 一个完整的立体权重块，形状 `(C_in, kH, kW)`。一个 filter 对应一个输出通道 |
| kernel | filter 里的一层，形状 `(kH, kW)`。层数必须等于输入通道数 |
| 输入通道 | 上一层输出的通道数。原图是 3（RGB），特征图是上一层定的 64/128/… |
| 输出通道 | 等于 filter 的个数，由 `out_channels` 决定。`Conv2d(64,128,1)` 就是 128 个 filter |
| 1×1 卷积 | 核尺寸为 1 的卷积，只在当前位置做跨通道加权求和。等价于 `(C_out, C_in)` 矩阵在每个像素上复用 |
| 参数量 | `C_out × C_in × kH × kW + C_out`。64→128 的 3×3 是 73,856，1×1 是 8,320 |
| 参数共享 | 同一套权重在 H×W 所有位置复用。这是卷积参数量远小于全连接的原因 |

### 训练现象

| 数值分布漂移 | 同一层输出的均值方差在训练中持续变化。来源是输入分布、权重更新、层间累积。实测学习率 0.5 时 150 步后输出变 NaN |
| 退化问题 | 深网络的训练误差反而高于浅网络。不是过拟合，是优化困难。带 BN 时也存在 |
| 神经元死亡 | ReLU 在负区间梯度恒为 0，长期为负的通道权重不再更新。SiLU 在负区间有非零梯度，不会死 |
