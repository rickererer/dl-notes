# 扩散模型的前向过程：从加噪定义到闭式解

> 对应 HuggingFace《The Annotated Diffusion Model》第 1、2 节，2026-11-02 读完。
> 文中标「原文」的是文章的说法，标「实测」的是在本机（RTX 4050 Laptop 6G）跑出来的数。
> 后面几节（目标函数、U-Net、采样）还没读，本文只到 p_θ 的参数化。

这两节的骨架很短：前向逐步加噪、反向逐步去噪、反向分布算不出来所以用网络逼近。真正花时间的是中间那些式子为什么长这样。

## 一、原文说了什么

**第 1 节 What is a diffusion model 的四个点：**

加噪和去噪是一对互逆过程，都由 `t` 索引，共 `T` 步，原文说 DDPM 作者取 `T=1000`。

从 `t=0` 开始，`x_0` 是从数据分布里采的真实图；前向每步从高斯里抽噪声加到上一步的结果上。

原文有一句关键的话：给定足够大的 `T` 和一个 well behaved 的加噪 schedule，走完会得到一个各向同性高斯。

反向则是从纯噪声出发，逐步去噪回到 `x_0`。原文提到扩散模型的主要缺点是需要多次前向才能生成一张图，GAN 不需要。

**第 2 节 In more mathematical form 的三个点：**

前向写成条件分布 `q(x_t | x_{t-1})`。

反向的 `p(x_{t-1} | x_t)` 算不出来，因为它需要知道所有可能图像的分布。所以用网络来逼近，记作 `p_θ`，`θ` 是网络参数。

如果假设反向也是高斯，那它只需要两个参数：均值 `μ_θ` 和方差 `Σ_θ`。

原文到这里就停了，下一节才讲怎么定这两个东西。

## 二、三个设定把形式锁死

前向过程长什么样不是随便写的。三条约束叠起来，只剩一个自由度。

| 约束 | 不满足会怎样 |
|---|---|
| 均值必须依赖 `x_{t-1}` | 第一步就把信息丢光，没有「逐步」可言 |
| 必须是线性的 | 反向后验不再是高斯，闭式解崩掉 |
| 不能带常数偏置 | 终点均值不为 0，和采样起点对不上 |

第一条实测过：把均值设成 0，只走一步，与真实图像相关系数 `+0.0007`，方差 `0.0001`。所有样本塌到同一个常数附近，图彻底没了。

第三条也实测过：每步加常数 `0.01`，走满 1000 步后终点均值 `+1.1469`，方差 `1.006`。终点成了 `N(1.15, 1)`，不是标准正态。

第二条的原因在后面的推导里会看到：反向后验要用贝叶斯，而贝叶斯要求似然作为 `x_{t-1}` 的函数是高斯型。只有线性时对数密度才是抛物线。

## 三、单步分布与采样写法

定义是：

```
q(x_t | x_{t-1}) = N( √(1-β_t)·x_{t-1},  β_t·I )
```

第一个参数是均值，第二个是协方差。`β_t` 是这一步新增噪声的**方差**（不是标准差），从 `1e-4` 线性增到 `0.02`。

要从这个分布里抽一个样本，用重参数化：

```
x_t = √(1-β_t)·x_{t-1} + √(β_t)·ε,      ε ~ N(0, I)
```

这一步不算推导，只是把「服从某分布」翻译成「怎么生成样本」。

系数为什么是 `√(1-β)` 而不是 `(1-β)`：为了让总方差守恒。设 `x_{t-1}` 方差为 1，加完是 `(1-β)·1 + β·1 = 1`。写成 `(1-β)` 每步损失约 2% 的方差，300 步后信号基本消失。

单步的剧烈程度随 `t` 变化（实测，T=1000）：

| t | β_t | 信号系数 | 噪声系数 | 单步信噪比 |
|---|---|---|---|---|
| 1 | 0.00010 | 0.99995 | 0.0100 | 100.0 |
| 500 | 0.01004 | 0.99497 | 0.1002 | 9.9 |
| 1000 | 0.02000 | 0.98995 | 0.1414 | 7.0 |

第一步几乎不动，最后一步改动明显。这个不均匀是线性 schedule 的固有特征，后面讲 schedule 时再说。

## 四、闭式解

单步式子连用两次能不能合并。把 `x_1` 代进第二步：

```
x_2 = √α₂·(√α₁·x_0 + √β₁·ε₁) + √β₂·ε₂
    = √(α₁α₂)·x_0 + √(α₂β₁)·ε₁ + √β₂·ε₂
```

信号项直接相乘。噪声项系数不同，靠一条性质合并：**两个独立高斯相加，方差相加**。

```
N(0, a²) + N(0, b²) = N(0, a² + b²)
```

所以噪声方差是 `α₂β₁ + β₂`。化简：

```
α₂β₁ + β₂ = α₂(1-α₁) + β₂
          = α₂ - α₁α₂ + β₂
          = (α₂ + β₂) - α₁α₂
          = 1 - α₁α₂
```

最后一步用了 `α₂ + β₂ = 1`。于是：

```
x_2 = √(ᾱ₂)·x_0 + √(1-ᾱ₂)·ε,      ᾱ₂ = α₁α₂
```

归纳下去，第 t 步是：

```
x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε,      ᾱ_t = ∏(1-β_s)
```

训练时拿到任意 `t`，都能一次算出 `x_t`，不用真的从 `x_0` 走 t 步。复杂度从 O(t) 降到 O(1)，DDPM 训得动靠的就是这一步。

实测三个时间点（T=300 的设置）：

| t | ᾱ | 信号系数 | 与原图相关系数 | 标准差 |
|---|---|---|---|---|
| 0 | 0.9999 | 0.9999 | +1.000 | 0.52 |
| 150 | 0.4623 | 0.680 | +0.516 | 0.79 |
| 299 | 0.0481 | 0.219 | +0.185 | 0.98 |

t=0 相关 1.000 说明没加噪，t=299 标准差接近 1、相关只剩 0.185，说明基本是噪声。

## 五、各向同性高斯

这一段我第一遍读的时候跳过去了，觉得是个数学细节。后来发现它决定了采样第一行代码能不能写。

原文说的「走完 T 步得到各向同性高斯」，实测可以验证。拿 2000 张 Fashion-MNIST 真实图走满 1000 步：

```
ᾱ_T = 4.04e-05      信号系数 0.0064      噪声系数 1.0000

全体像素均值      -0.0034
全体像素标准差     0.9997
像素间相关系数     均值 0.0000，最大绝对值 0.101
```

对比原始图：均值 `-0.4321`，标准差 `0.7070`，像素之间还高度相关。加噪把结构全抹平了。

各向同性的意思是协方差是「标量 × 单位阵」：

```
对角全相等     每个维度的方差一样
非对角为 0     任意两维不相关
```

两个条件要同时满足。`diag(1,4)` 是对角矩阵、各维不相关，但不是各向同性。实测把样本投影到不同角度算方差：

| 角度 | 协方差 `I` | 协方差 `diag(1,4)` |
|---|---|---|
| 0° | 1.003 | 0.994 |
| 45° | 1.005 | 2.510 |
| 90° | 1.000 | 4.007 |

`I` 在任何方向都一样，`diag(1,4)` 转个角度从 1 变到 4，等概率面是椭圆。

**为什么必须各向同性**：采样第一步是 `torch.randn`，它给的就是 `N(0, I)`。如果终点是各向异性的，抽出来的起点就落在模型没见过的区域。要救就得知道那个协方差矩阵，784 维的话是 61 万个参数，还要保证半正定。

## 六、不收缩会怎样

把均值改成 `x_{t-1}` 本身，其余不变，跑满 1000 步（实测 500 张图）：

| 写法 | 最终方差 | 与原图相关系数 |
|---|---|---|
| `√(1-β)·x + √β·ε` | 1.01 | +0.002 |
| `x + √β·ε` | 10.54 | +0.215 |

不收缩那组，图还留在噪声里。信号系数恒为 1，噪声只涨到 `√Σβ = 3.17`，信噪比停在 0.32，永远到不了纯噪声。

学术界把这两族分开叫（Song 那篇 SDE 论文的术语）：DDPM 这种是方差保持（VP），终点固定 `N(0, I)`；不收缩那种是方差爆炸（VE），终点是 `N(0, σ_T²)`，采样时得额外知道 `σ_T`。

DDPM 选 VP，换来「起点永远标准正态」这个便利。

## 七、variance schedule

β 序列怎么排，叫 variance schedule，也叫 noise schedule。原文列了四种。

`T=1000` 下实测：

| schedule | β_1 | β_T | ᾱ@25% | ᾱ@50% | ᾱ@75% | ᾱ_T |
|---|---|---|---|---|---|---|
| linear | 1e-4 | 0.0200 | 0.5241 | 0.0786 | 0.0034 | 4.0e-5 |
| quadratic | 1e-4 | 0.0200 | 0.8215 | 0.3332 | 0.0386 | 7.3e-4 |
| sigmoid | 1.5e-4 | 0.0200 | 0.9037 | 0.3019 | 0.0057 | 4.0e-5 |
| cosine | 1e-4 | 0.9999 | 0.8467 | 0.4937 | 0.1442 | 2.4e-10 |

**linear 的问题在 50% 那列：0.0786。** 走到一半，信号只剩 7.9%，后面 500 步基本在学纯噪声。这就是「前段太慢、后段太快」。

cosine 在 50% 时是 0.4937，正好一半，整条曲线更接近直线。

判断标准：**`ᾱ` 随 t 的曲线越接近线性越好**，因为那意味着每个时间步的去噪难度分布均匀。

cosine 表里 `β_T = 0.9999` 是被 clip 后的值。原始公式在 `t=T` 时 `ᾱ_T` 正好为 0，导致最后一步 `β = 1`，等于一步把图抹掉。所以实现里会 `torch.clip(betas, 0.0001, 0.9999)`。

「well behaved」可以量化成三条：

```
起点要轻      β_1 很小，第一步几乎不改图
中间要平滑    不能跳变，否则某些 t 上任务难度骤变
终点要干净    ᾱ_T 接近 0，否则采样起点和训练分布不一致
```

第三条可以粗估验证：线性 schedule 下 `ᾱ_T ≈ exp(-Σβ)`。`Σβ = 1000 × (1e-4 + 0.02)/2 = 10.05`，`e^(-10.05) ≈ 4.3e-5`，与实测 `4.04e-5` 接近。

## 八、反向参数化：为什么只要两个数

`p(x_{t-1} | x_t)` 算不出来。原文的做法是假设它也是高斯，那只需要 `μ_θ` 和 `Σ_θ` 两个参数。

DDPM 把方差直接固定成 `β_t·I`，不学。只剩均值要猜。这一步降级有代价（生成质量差一点），换来训练稳定。Improved DDPM 后来把方差变成可学的，是它主要的改进点之一。

网络不直接输出 `μ_θ`，而是输出噪声 `ε_θ`，再换算：

```
μ_θ = 1/√α_t · ( x_t - β_t/√(1-ᾱ_t) · ε_θ(x_t, t) )
```

### 这个式子怎么来的

起点是真实后验的均值，它需要 `x_0`。把 `x_0` 用 `x_t` 和 `ε` 反解替换掉：

```
x_0 = (x_t - √(1-ᾱ_t)·ε) / √ᾱ_t
```

代进后验均值（见下一节的推导）：

```
μ̃ = [√ᾱ_{t-1}β_t/(1-ᾱ_t)]·x_0 + [√α_t(1-ᾱ_{t-1})/(1-ᾱ_t)]·x_t
```

注意 `√ᾱ_{t-1}/√ᾱ_t = 1/√α_t`，第一项变成：

```
(1/√α_t) · β_t/(1-ᾱ_t) · (x_t - √(1-ᾱ_t)·ε)
```

合并 `x_t` 的两个系数：

```
(1/√α_t)·β_t/(1-ᾱ_t) + √α_t(1-ᾱ_{t-1})/(1-ᾱ_t)
= (1/√α_t) · [β_t + α_t(1-ᾱ_{t-1})]/(1-ᾱ_t)
= (1/√α_t) · [(1-α_t) + α_t - ᾱ_t]/(1-ᾱ_t)
= (1/√α_t) · (1-ᾱ_t)/(1-ᾱ_t)
= 1/√α_t
```

中间用了 `β_t = 1-α_t` 和 `α_tᾱ_{t-1} = ᾱ_t`，括号里正好化成 `1-ᾱ_t`，和分母抵消。所以：

```
μ̃ = 1/√α_t · ( x_t - β_t/√(1-ᾱ_t) · ε )
```

把 `ε` 换成 `ε_θ` 就是那个式子。实测三条路线（用 `x_0` 直接算、`x_0` 换成反解式、化简式）在 `t=500` 时给出同一个值 `1.03424966`。

两个系数的量级（实测）：

| t | `1/√α_t` | `β_t/√(1-ᾱ_t)` |
|---|---|---|
| 1 | 1.00005 | 0.0100 |
| 500 | 1.00506 | 0.0105 |
| 1000 | 1.01015 | 0.0200 |

括号里只减掉 1% 到 2% 的噪声，外面放大 0.05% 到 1%。所以 `μ_θ ≈ x_t`，每步只是小修。这和「每步只加一点点噪声」是对称的。

## 九、后验均值怎么推出来的

`q(x_{t-1} | x_t, x_0)` 是条件高斯，靠贝叶斯和两个高斯相乘。

### 贝叶斯展开

记 `z = x_{t-1}`，联合分布 `P(z, x_t | x_0)` 有两种拆法：

```
先 z 后 x_t     P(z|x_0) · P(x_t | z, x_0)
先 x_t 后 z     P(x_t|x_0) · P(z | x_t, x_0)
```

第一种拆法里用掉了唯一的扩散假设：**马尔可夫性**，给定 `z` 之后 `x_t` 与 `x_0` 无关，所以 `P(x_t|z,x_0) = P(x_t|z)`。

两式相等移项：

```
P(z | x_t, x_0) = P(x_t|z) · P(z|x_0) / P(x_t|x_0)
```

分母里没有 `z`，只是归一化常数，推导时可以扔掉。

### 两个因子都写成关于 z 的高斯

似然 `q(x_t|z) = N(x_t; √α_t·z, β_t)`，配方成 `z` 的分布：

```
‖x_t - √α_t z‖²/(2β_t) = α_t‖z - x_t/√α_t‖²/(2β_t)
```

所以中心 `m₁ = x_t/√α_t`，方差 `v₁ = β_t/α_t`。

先验 `q(z|x_0) = N(z; √ᾱ_{t-1}x_0, 1-ᾱ_{t-1})`，即 `m₂ = √ᾱ_{t-1}x_0`，`v₂ = 1-ᾱ_{t-1}`。

### 两个高斯相乘

```
1/v = 1/v₁ + 1/v₂            （精度相加）
μ   = v·(m₁/v₁ + m₂/v₂)      （按精度加权）
```

方差：

```
1/v = α_t/β_t + 1/(1-ᾱ_{t-1})
    = [α_t(1-ᾱ_{t-1}) + β_t] / [β_t(1-ᾱ_{t-1})]
```

分子 `α_t - ᾱ_t + β_t = 1 - ᾱ_t`，所以：

```
v = β_t(1-ᾱ_{t-1})/(1-ᾱ_t)      ← 代码里的 posterior_variance
```

均值，把 `v` 代回分别乘两个权重：

```
x_t 系数 = v·√α_t/β_t        = √α_t(1-ᾱ_{t-1})/(1-ᾱ_t)
x_0 系数 = v·√ᾱ_{t-1}/(1-ᾱ_{t-1}) = β_t√ᾱ_{t-1}/(1-ᾱ_t)
```

### 数值验证

`t=500`，`x_0=1.3`，`x_t=1.0364`，在一根细网格上直接算 `log q` 后验，找峰值和曲率：

| 量 | 网格算出 | 公式给出 |
|---|---|---|
| 均值 | 1.03428325 | 1.03428325 |
| 方差 | 0.01003135 | 0.01003136 |

八位有效数字一致。

**这里踩了个坑**：第一次用 float32 算，方差得到 `0.00084`，差了 12 倍。因为 `log q` 的绝对值到几千，二阶差分只有 1e-4 量级，被浮点精度吃掉了。换 float64 才对上。

### 精度加权的直观

两个因子在 `t=500` 时的参数：

| 因子 | 中心 | 方差 | 精度 | 权重 |
|---|---|---|---|---|
| 似然 | 1.0416 | 0.010142 | 98.60 | 0.989 |
| 先验 | 0.3663 | 0.920616 | 1.09 | 0.011 |
| 后验 | 1.0343 | 0.010031 | 99.69 | 1.000 |

似然和先验的中心差 0.67，但似然精度是先验的 90 倍，所以后验几乎完全听似然的，先验只把结果拉了 0.007。

## 十、三个「步数」别混

| 说法 | 数值 | 含义 |
|---|---|---|
| 扩散步数 `T` | 1000 | 加噪链有几级，超参 |
| 训练步数 | 469 / epoch | batch=128、6 万样本，一轮更新 469 次 |
| 采样步数 | 1000 | 生成时网络前向几次 |

实测（batch 16，本机 4050）：

```
单次前向      30 ms
300 步采样    8.9 s
1000 步采样   30 s
```

采样的计算量严格是 O(T)，这是扩散模型慢的根源。DDIM 那类工作就是把 `T` 压到 50 左右，这也是 0.2 要看的第一个优化。

而训练成本跟 `T` 无关：随机抽一个 `t`，用闭式解造出 `x_t`，网络只跑一次。

`T` 改了模型必须重训，因为 `β` 序列变了，每个 `t` 对应的噪声水平也变了。

## 概念清单

### 前向过程

| 概念 | 含义 |
|---|---|
| 前向过程 | `q(x_t∣x_{t-1}) = N(√(1-β_t)x_{t-1}, β_t I)`。逐步加噪，无参数，不需要训练 |
| 反向过程 | `p_θ(x_{t-1}∣x_t)`，从噪声回到数据。真实分布算不出来，用网络逼近 |
| 重参数化 | `N(μ,σ²)` 抽样等于 `μ + σ·ε`，`ε~N(0,I)`。把「服从分布」变成「怎么生成」 |
| 闭式解 | `x_t = √ᾱ_t x_0 + √(1-ᾱ_t) ε`。任意 t 一步算出，训练成本 O(1) 而不是 O(t) |
| 独立高斯方差相加 | `N(0,a²)+N(0,b²)=N(0,a²+b²)`。闭式解能成立的核心工具 |
| 方差保持 VP | DDPM 这一族，每步 `c²+β=1`，终点固定 `N(0,I)` |
| 方差爆炸 VE | `x_t = x_{t-1} + √(σ_t²-σ_{t-1}²)ε`，终点 `N(0,σ_T²)`，采样要知道 σ_T |

### 分布

| 概念 | 含义 |
|---|---|
| 协方差 | `Cov(X,Y)=E[(X-μ_X)(Y-μ_Y)]`。正数同涨同落，负数一涨一跌 |
| 协方差矩阵 | 对角线是各维方差，非对角线是两两协方差。784 维就是 784×784 |
| 各向同性高斯 | 协方差等于「标量 × 单位阵」。对角全相等、非对角为 0，任意方向方差相同 |
| 各向异性 | `diag(1,4)` 这种：对角但不等。45° 方向方差 2.51，0° 是 1，90° 是 4 |
| 条件高斯 | `q(x_{t-1}∣x_t,x_0)` 仍是高斯，因为贝叶斯分子是两个高斯相乘 |
| 两个高斯相乘 | `1/v = 1/v₁+1/v₂`，`μ = v(m₁/v₁+m₂/v₂)`。精度相加、按精度加权 |
| 精度 | `1/σ²`。t=500 时似然精度 98.6、先验 1.09，后验几乎由似然决定 |

### 后验与参数化

| 概念 | 含义 |
|---|---|
| 后验均值 | `μ̃ = [√ᾱ_{t-1}β_t/(1-ᾱ_t)]x_0 + [√α_t(1-ᾱ_{t-1})/(1-ᾱ_t)]x_t` |
| 后验方差 | `β̃_t = β_t(1-ᾱ_{t-1})/(1-ᾱ_t)`，代码里的 `posterior_variance` |
| 马尔可夫性 | 给定 `x_{t-1}` 后 `x_t` 与 `x_0` 无关。贝叶斯展开里唯一用到的扩散假设 |
| μ_θ 公式 | `μ_θ = 1/√α_t (x_t - β_t/√(1-ᾱ_t) ε_θ)`。把 `x_0` 反解后代入、合并系数得来 |
| 为什么预测噪声 | `ε` 的尺度恒为 `N(0,I)`；直接预测 `x_0` 时误差尺度随 t 剧烈变化 |
| 固定方差 | DDPM 让 `Σ_θ = β_t I` 不学，换训练稳定。Improved DDPM 才学方差 |

### schedule

| 概念 | 含义 |
|---|---|
| variance schedule | `β_1...β_T` 的安排，也叫 noise schedule。线性、二次、sigmoid、cosine 四种 |
| well behaved | 起点轻、中间平滑、终点 `ᾱ_T≈0` 三条。量化检查看 `ᾱ_T` |
| ᾱ_T 粗估 | 线性 schedule 下 `ᾱ_T ≈ exp(-Σβ)`。T=1000 时 `e^(-10.05)≈4.3e-5`，实测 4.04e-5 |
| 线性 schedule 的问题 | 50% 时 `ᾱ` 只剩 0.0786，后半程基本在学纯噪声 |
| cosine schedule | 50% 时 `ᾱ=0.4937`，前段更慢、后段均匀。末尾 `β_T` 会到 1，实现里要 clip |
| 单步信噪比 | `√(1-β)/√β`。线性 schedule 下从 100:1 降到 7:1 |

### 实际开销

| 概念 | 含义 |
|---|---|
| 训练成本 | 与 T 无关。随机抽 t，闭式解造 x_t，一次前向 |
| 采样成本 | O(T)。每步都要跑网络，1000 步就是 1000 次前向 |
| 实测耗时 | 单次前向 30 ms（batch 16），300 步 8.9 s，1000 步 30 s |
| T 与权重绑定 | 改 T 就改了 β 序列，每个 t 的噪声水平变了，模型必须重训 |
